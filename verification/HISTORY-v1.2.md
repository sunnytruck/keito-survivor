# 岩尊降臨 — ねむれる神の八分間

岩尊けいとの部屋を舞台にした、ブラウザ用の1キャラ・1ステージのサバイバルアクションです。ビルドや依存パッケージは不要です。`dist/` を静的HTTPサーバーで配信すると遊べます。

## 操作

- WASD / 矢印キー：移動。スマホでは画面をドラッグ。
- 攻撃：自動。足元の半径10の円がダメージ判定です。
- 緑の信仰：経験値。レベルアップ時に3択から選択。1 / 2 / 3 キーでも選べます。
- Esc / P：ポーズ。M：ミュート。
- 設定：音量、ミュート、画面揺れ、ダメージ数字、顔写真の差し替え。

通常進行8分で最終ボスが出現し、撃破でクリアします。3分と6分の中ボスが落とす神宝で、攻撃Lv.5＋対応補助を持つ能力を進化できます。

## 素材

添付ファイルは実写写真ではなく「じっと教」のイラストだったため、その画像の顔をCanvasで切り抜いて描画しています。本人の顔を新たに生成していません。設定から本人写真に差し替え、位置と拡大率を調整できます。差し替え画像・設定・自己ベストはブラウザのlocalStorageに保存し、外部送信しません。

部屋、家具、神殿、敵、各能力、UIの線画は独自のCanvas / SVG表現です。音楽・効果音はWeb Audioによるオリジナルの合成音です。Webフォントが取得できない環境ではシステムフォントを使います。装飾に移動を妨げる判定はありません。

## 構成

- `dist/engine.mjs`：戦闘、敵、能力、経験値、強化、進化、勝敗、再挑戦。
- `dist/art.mjs`：Canvas描画、添付画像の顔、独自の敵・家具・神殿。
- `dist/app.mjs`：UI、入力、音、設定、顔写真の差し替え。
- `dist/index.html` / `style.css`：日本語画面、レスポンシブUI。
- `verify.mjs`：戦闘ロジックの回帰検証（Node標準機能のみ）。
- `verify-app.mjs`：実アプリモジュールの起動・イベント接続・Canvas描画検証（作業環境のnative Canvasを使用）。

## Version 1.2 — 時間帯ごとの強化世代と精鋭（2026-10-18）

敵が1分ごとに新しい強化段階へ進みます。新しく出る同種の敵だけが強化され、既に出現している敵のHPは突然増えません。敵勢力の段階を画面に表示し、切り替わりにカットインを出します。

| 時間 | 敵勢力 | 通常の時計のHP | 通常出現の上限 |
|---|---|---:|---:|
| 0:00 | 気配 | 20 | 180 |
| 1:00 | 侵入 | 50 | 240 |
| 2:00 | 増援 | 120 | 300 |
| 3:00 | 包囲 | 320 | 360 |
| 4:00 | 強襲 | 900 | 400 |
| 5:00 | 狂信 | 2200 | 440 |
| 6:00 | 猛攻 | 4800 | 480 |
| 7:00 | 終末 | 8400 | 520 |
| 8:00〜 | 夜更かし | 13000 | 520 |

- 2分以降は精鋭が混ざります。金のひし形・輪郭と少し大きい体で区別でき、同段階の通常個体の2.4倍のHPを持ちます。
- 後半ほど出現人数・密度・接近速度・攻撃力が上がり、重い敵は押し返されにくくなります。突進・範囲攻撃の予告は維持。
- ボスHPは6000 / 14000 / 36000。8分に最終ボスが出現するルールを維持。
- 武器・補助の威力、弾数、発射間隔、進化性能はVersion 1.1.1と同じ。100通りの能力数値とプレイヤーの初期状態の一致を確認しています。
- 大群化で経験値・回復・レベルアップ無敵が過剰に増えるのを抑えるため、敵の経験値を段階ごとに調整。HP24回復アイテムのドロップに10秒の間隔を設けています。回収範囲や神威解放の攻撃性能は同じです。
- 自然進行の移動入力5シナリオ中4シナリオでクリア。75秒以降は3.5秒ごとに0.6秒だけ動く入力2シナリオは、旧版では両方クリア、新版では378.40秒・388.07秒で敗北。検証用の無敵・HP補充・時間スキップは使用していません。
- 最初から全能力最大の特殊な静止試験は510.97秒でクリアしました。通常進行の放置に近い入力とは区別しています。放置で絶対に勝てないことや、人間のプレイ感を保証する検証ではありません。
- 23項目の戦闘検証、12項目のアプリ接続検証、通常敵520体＋ボス3体・精鋭84体を含むnative Canvas描画を確認。実ブラウザでの操作・性能は未確認。

詳細：`verification/2026-10-18-escalation-balance.json`、`verification/2026-10-18-escalation-logic.json`。

## Version 1.1.1 — 敵の硬さ・密度の調整（2026-10-18）

プレイヤーの攻撃・補助能力の全レベルと進化の数値、HP・移動・回復・神威解放はVersion 1.1のままです。敵の攻撃力や弾速も変更していません。

- 通常敵の基礎HP：時計16→20、岩38→54、モニター24→32、耐久型90→138。時間経過によるHP倍率を最大2.8倍→3.7倍に変更。8分時点の通常敵HPは旧版の約1.65〜2.03倍です。
- ボスHP：3分ボス2600→3500、6分ボス4800→6600、最終ボス12500→17000。
- 最初の30秒は通常出現の頻度を維持。その後段階的に増やし、3分以降は最大45%増加。
- 時計の群れは最大32体→48体、周期45秒→36秒。通常出現の管理上限260体→320体。
- 19項目の戦闘検証と12項目のアプリ接続検証を通過。プレイヤーの100通りの能力数値（10能力×5レベル×進化フラグ）と初期状態を前版と比較して一致を確認。
- 同じ回収方針による移動入力5シナリオはいずれもクリアし、通常回収3シードの撃破数は旧版4492〜5026体から6406〜6690体へ増加。最大能力で静止する試験は215.08秒で敗北。人間のプレイ感や実ブラウザの性能は未確認です。

## Version 1.1 — 難度と手応えの調整（2026-10-18）

- 初期HP150、移動速度215。初期の「うきき」は威力28・3発・0.72秒間隔・射程330。時計は序盤に一撃で倒せます。
- 信仰の基本回収半径130。強化を選んだ直後と神威解放中は落ちた信仰を自動回収。初期の強化候補に所持攻撃の強化と、新しい直接攻撃を含めます。
- レベルアップでHP12回復。緑の＋を拾うとHP24回復。6秒間被弾しないと毎秒1.6ずつ自然回復。
- 60体の撃破で「神威解放」。周囲の爆発、近い敵弾の消去、信仰の回収、HP12回復。6秒間、攻撃威力+35%、待ち時間−25%。爆発自体の撃破ではゲージを再充填しません。
- やわらかい時計の群れ、連続撃破表示、技名のカットイン、着弾・粉砕・神化・ボス登場と撃破の演出、効果音とリズムのある音楽を追加。
- 遠距離敵の割合を下げ、弾速・突進速度を緩和。ボスの攻撃予告を延長。長時間停止し続けた場合の赤い予告は移動で回避できます。
- 画面揺れの無効設定を維持。敵弾はCanvasの攻撃演出より手前に描画。

`node verify.mjs`（19項目）、`node verify-app.mjs`（12項目）、15種類のCanvas演出を3段階の残り時間で描画する確認を実施。

`node verify-balance.mjs [旧engine.mjsの絶対パス]` は無敵・HP補充・時間スキップを使わず、回収に向かう単純な入力で比較します。旧版の3シードは52.32〜94.63秒で敗北し、新版の3シードは493.97〜531.52秒でクリア。初回強化は5シードで19.12〜21.38秒。最大能力のまま静止する試験は210.55秒で敗北しました。実ブラウザや人間によるプレイ感の確認とは区別します。詳細は `verification/2026-10-18-balance.json` に保存しています。
